Secure Messaging over TLS 1.3 with End-to-End Encryption

Two clients chat through a relay server across a network of two routers and three subnets. TLS 1.3 protects every hop, and end-to-end encryption hides message bodies from the server itself. Connect the clients, send a message and see what an eavesdropper and the server can read in each security mode.
